# 앱 사용 통계

PostHog의 이벤트 수집 API를 직접 호출한다. SDK 자동 클릭 수집·화면 녹화·원격 스크립트는 사용하지 않는다. 2026-10-13 사용자 제공 프로젝트 수집 키와 US 리전을 연결했다. 0.2.8 직접 설치판에 포함했다. src/features/analytics/config.json의 projectKey에 프로젝트 수집 키(phc_), region에 US 또는 EU를 지정한다. 개인 API 키를 넣지 않는다. 설정 키가 없으면 UI는 준비 중으로 표시되고 어떤 통계도 전송하지 않는다.

사용 통계 공유는 기본 꺼짐이며 사용자 선택을 설정 파일에 저장한다. 설치별 무작위 ID로 재방문을 집계하므로 완전 익명이라고 안내하지 않는다. IP 위치 추정과 사용자 프로필 생성을 끄고 채널·방송사·프로그램명, 재생 URL, 오류 원문은 보내지 않는다. 전송 서버에는 네트워크 연결상 IP가 노출될 수 있다. 고지에 PostHog 제공자와 선택 리전을 명시해야 한다.

이벤트: app_opened, playback_started, playback_failed, channel_changed(method), feature_used(feature), listening_summary(seconds), app_updated(previous_version). OS·앱 버전을 함께 보낸다. 재생 성공은 실제 playing 이벤트 기준이다. 청취 시간은 재생 구간 종료와 30분마다 집계하며 강제 종료 직전 구간은 누락될 수 있다. 버전 변화 이벤트는 업데이트 경로를 구분하지 않는다. 시작 이벤트는 앱 프로세스 단위이며 자정 넘어 열린 앱은 새 실행으로 세지 않는다.

평균 하루 20건은 추정치다. 설치당 UTC 하루 100건 상한을 저장하고 초과는 버린다. 따라서 사용량이 많은 설치는 일부 기록이 누락된다. 전체 무료 사용을 보장하는 상한은 아니며 PostHog에서 Product Analytics 무료 월 100만 건과 과금 한도를 설정하고 실제 수집량을 관찰해야 한다. 네트워크 실패는 재시도하지 않아 과도한 전송을 피한다. 5초 제한, 통계 오류는 청취와 무관하다. 설정 해제 시 진행 요청을 취소하지만 이미 전송된 기록은 취소되지 않는다.

프로젝트 키·US 리전 연결을 완료했다. 각 OS 수신/옵트아웃 확인 → 고지 확인 → 출시 순서다. Mac 설치본의 조작·설정 저장을 확인했고 사용자가 PostHog 수신을 확인했다. Windows/Linux 실전송·무료 과금 한도는 미검증이다. 웹 GA와 사용자 ID는 연결하지 않는다.

2026-10-13 연결 검증: US 수집 API에 개인정보 없는 `integration_test` 한 건을 전송해 HTTP 200 / `{"status":"Ok"}` 응답을 확인했다. 테스트 ID는 `motungi-radio-integration-test-2026-10-13`, `test_event=true`이며 실제 이용자 통계에서 제외한다. 이는 수집 API 응답 확인이며 대시보드 표시나 설치 앱 전송의 검증은 아니다. 프런트 테스트 59개와 직접 배포 웹 빌드가 통과했다.

2026-10-13 로컬 설치 시험: 직접 배포 debug 앱을 /Applications/모퉁이 라디오.app에 설치하고 ad-hoc 서명 무결성을 확인했다. 기존 설치본은 ~/Applications/모퉁이 라디오-backup-20261013-204551.app에 보관했다. 네이티브 UI에서 무음 시작, 통계 기본 꺼짐, 동의 켜기와 재시작 후 유지, MBC 표준FM 연결 중→재생 상태→정지를 확인했다. 실제 소리 청취 여부는 판정하지 않았다. 통계 공유와 고정은 시험 후 원래 꺼짐으로 복원했다. PostHog 브라우저가 로그인 화면이어서 설치 앱 이벤트의 서버 수신과 해제 후 미수신은 확인하지 못했다. 앞선 synthetic API 성공을 설치 앱 성공으로 합산하지 않는다. 설치본은 로컬 시험용이며 Developer ID 서명·공증 및 공개 배포를 수행하지 않았다.

통계 보관 운영 정책은 사용자 결정에 따라 90일이다. PostHog 프로젝트의 보관/삭제 설정 적용 여부는 아직 확인하지 못했으며 자동 삭제가 검증됐다고 안내하지 않는다.

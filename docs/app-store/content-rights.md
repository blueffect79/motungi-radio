# 방송 콘텐츠 권한 확인표 — 제출 전

공식 원천의 연결 성공은 이용 허가를 증명하지 않는다. docs/station-support.md의 연결 근거와 아래 권한 근거를 별도로 관리한다. 권리자에게 문의를 보내지는 않았다.

|방송사|확인할 범위|현재 권한 근거|
|---|---|---|
|KBS|스트리밍·편성표·프로그램 이미지·명칭|제3자 앱 허용 조건 미정리|
|MBC|스트리밍·편성표·이미지·명칭|findings.md의 이용 조건 메모 존재, 명시적 제3자 앱 허가로 보지 않음|
|SBS|스트리밍·편성표·이미지·명칭|제3자 앱 허용 조건 미정리|
|CBS|스트리밍·편성표·이미지·명칭|제3자 앱 허용 조건 미정리|
|EBS|스트리밍·편성표·명칭|제3자 앱 허용 조건 미정리|
|cpbc·BBS·FEBC·WBS|각 방송사별 스트리밍·정보·명칭|제3자 앱 허용 조건 미정리|
|TBN 경인|스트리밍·정보·명칭|제3자 앱 허용 조건 미정리|

각 항목에 이용 약관 URL·확인일·허용 조항 또는 권리자 회신·허용 지역·이미지 사용 여부·만료일을 기록한다. 비영리·무료·로컬 직접 연결 여부와 녹음/저장 없음도 정확히 설명한다. 증빙에는 토큰이나 일시 스트리밍 URL을 넣지 않는다.

허용 여부가 모호하면 앱 심사에서 확인 가능하다고 단정하지 않는다. 필요한 경우 사용자에게 권리자 문의 초안을 제시하고 발송 지시를 받은 뒤 연락한다. 지원 채널 축소나 이미지 제외는 제품 범위 변경이므로 별도로 결정한다.

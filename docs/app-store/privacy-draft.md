# 개인정보 안내 초안 — 게시 전 확인 필요

모퉁이 라디오는 계정 없이 이용하는 라디오 앱입니다. 즐겨찾기, 음량, 마지막 채널, 화면 설정은 사용자의 기기에 저장합니다. 방송 재생·프로그램 정보 요청은 해당 방송사의 서버로 직접 전달됩니다. 방송사에는 통신에 필요한 IP 주소 등이 전달되며, 방송사별 처리방침이 적용됩니다.

## 선택형 사용 통계

현재 배포 준비 코드에는 PostHog US 프로젝트가 연결되어 있습니다. 통계 공유는 기본 꺼짐이며, 설정에서 사용자가 ‘사용 통계 공유’를 켠 경우에만 수집합니다.

- 목적: 재생 오류와 기능 사용 현황을 확인해 앱을 개선
- 항목: 무작위 설치 식별자, OS 종류, 앱 버전, 실행·재생 성공/실패·채널 이동 방식·즐겨찾기/편성표/고정 사용 여부, 청취 시간 요약, 버전 변경
- 수집하지 않는 항목: 이름·이메일·채널명·프로그램명·스트리밍 URL·오류 원문·화면 녹화·오디오
- 처리 서비스: PostHog Cloud. 미국(US) 리전. 수탁/국외이전 관련 안내는 출시 전 확정해야 함
- IP: 앱은 IP 속성을 제거하도록 요청하고 위치 추정을 비활성화함. 네트워크 전달 과정에서 수신 서버는 연결 IP를 볼 수 있으므로 ‘IP가 전혀 전달되지 않는다’고 안내하지 않음
- 보관 정책: 90일(운영자 승인). PostHog 보관/삭제 설정 적용 확인 필요
- 중단: 설정에서 공유를 끄면 이후 전송 중단. 이미 도착한 기록은 자동 삭제되지 않음
- 문의·삭제 요청 창구: 공개 전에 운영 연락 방법 확정. 공개 GitHub 이슈에 개인 식별자나 민감한 정보 입력을 요구하지 않음

## App Privacy 작성 메모

실제 연결된 버전에서 식별자·제품 상호작용·사용 데이터의 분류와 연결 여부를 Apple 질문에 맞춰 확인한다. 무작위 설치 ID가 지속되므로 단순히 ‘완전 익명’ 또는 ‘데이터 수집 없음’으로 작성하지 않는다. 웹 GA와 앱 사용자 ID는 연결하지 않는다. 광고 목적 추적과 다른 회사 데이터 결합은 구현하지 않는다. 개인정보 표시와 개인정보 매니페스트/API 사용 사유 검사는 별개로 확인한다.

이 문서는 기술 구현을 설명하는 초안이며 게시된 개인정보처리방침이나 법률 검토 결과가 아니다.

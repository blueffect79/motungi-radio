# 방송과 청취 규칙

채널은 하나의 실제 방송이다. 목록의 묶음은 채널이 아니다. 일반 지역방송은 제외하며 TBN만 지역별 채널을 제공한다. TBN은 전체 목록에서 한 행이고, 직접 즐겨찾기한 지역만 즐겨찾기에 각각 나타난다.

사용자의 마지막 재생 선택이 이긴다. 저장이나 주소 조회가 늦게 끝나도 이전 선택이 되살아나지 않는다. 정지는 진행 중 연결을 취소한다. 창 숨김은 정지가 아니며, 명시적 앱 종료는 청취를 끝낸다.

TBN 청취 또는 연결 중 지역 변경은 새 지역으로 전환한다. 정지 상태나 다른 방송 청취 중에는 지역 설정만 바뀌며 소리가 시작되거나 다른 방송을 빼앗지 않는다. 판단 기준은 지역을 선택한 순간이다.

실행 시 마지막 선택·음량·즐겨찾기를 복원하지만 재생하지 않는다. 첫 실행 음량은 50이며 자동 실행은 기본 꺼짐이다. 로그인 자동 실행은 아이콘만 표시한다. OS에서 바꾼 자동 실행 상태를 앱에 저장된 희망값으로 덮어 표시하지 않는다.

현재 프로그램은 한국시간으로 시작 포함·종료 제외 구간에 들어가는 항목이다. 자정 직후에는 전날 시작한 구간도 검사한다. 충돌·만료·조회 실패는 확인 불가이며 이전 제목을 현재 방송으로 계속 표시하지 않는다. 편성표 계산 결과에는 편성표 기준을 붙인다. 정보 오류는 정상 오디오를 중단하지 않는다.

절전 복귀와 네트워크 복구는 재생 의도가 남아 있을 때만 같은 채널을 다시 연결한다. 정지한 사용자를 자동 재생으로 되돌리지 않는다. 실패는 오류와 수동 재시도 수단으로 남긴다.

손상된 개인 설정은 유효한 필드만 복원한다. 사라진 즐겨찾기는 해제할 수 있고 다른 방송으로 임의 치환하지 않는다. 더 새로운 설정 버전을 만났을 때 기존 파일을 덮어쓰지 않는다.

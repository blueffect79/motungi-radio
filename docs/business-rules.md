# 방송과 청취 규칙

채널은 하나의 실제 방송이다. 일반 지역방송은 제외하며 TBN은 경인만 제공한다(2026-10-09 사용자 변경 결정). 이전 지역 카탈로그는 보존하지만 화면과 정보 조회에서 제외한다. 기존 다른 지역 즐겨찾기는 이용 불가 항목으로 남겨 해제할 수 있다.

사용자의 마지막 재생 선택이 이긴다. 저장이나 주소 조회가 늦게 끝나도 이전 선택이 되살아나지 않는다. 정지는 진행 중 연결을 취소한다. 창 숨김은 정지가 아니며, 명시적 앱 종료는 청취를 끝낸다.

전체와 즐겨찾기를 탭으로 나누고 같은 화면에서 채널을 중복 표시하지 않는다. TBN 지역 선택은 제공하지 않는다.

실행 시 마지막 선택·음량·즐겨찾기를 복원하지만 재생하지 않는다. 첫 실행 음량은 100이며 자동 실행은 기본 꺼짐이다. 로그인 자동 실행은 아이콘만 표시한다. OS에서 바꾼 자동 실행 상태를 앱에 저장된 희망값으로 덮어 표시하지 않는다.

현재 프로그램은 한국시간으로 시작 포함·종료 제외 구간에 들어가는 항목이다. 자정 직후에는 전날 시작한 구간도 검사한다. 충돌·만료·조회 실패는 확인 불가이며 이전 제목을 현재 방송으로 계속 표시하지 않는다. 플레이어에는 편성표 기준 문구를 넣지 않으며, 편성표 화면에서 원천 안내를 제공한다. 정보 오류는 정상 오디오를 중단하지 않는다.

절전 복귀와 네트워크 복구는 재생 의도가 남아 있을 때만 같은 채널을 다시 연결한다. 정지한 사용자를 자동 재생으로 되돌리지 않는다. 실패는 오류와 수동 재시도 수단으로 남긴다.

손상된 개인 설정은 유효한 필드만 복원한다. 사라진 즐겨찾기는 해제할 수 있고 다른 방송으로 임의 치환하지 않는다. 더 새로운 설정 버전을 만났을 때 기존 파일을 덮어쓰지 않는다.

라이트·다크·시스템 설정 따름과 기본·미니 모드를 로컬 설정에 기억한다. 음량과 음소거는 설정 화면에만 둔다. 미니 모드는 기존 창을 380px 폭과 내용에 맞는 높이(200~360px)로 줄이고 같은 재생기를 유지한다. 설정·편성표는 일시적으로 기본 크기로 열리며 돌아오면 미니 크기를 복원한다.

편성표는 제공된 날짜별로 지난·현재·다음 프로그램을 시간순으로 표시한다. 지난 방송은 회색, 현재 방송은 배경으로 표시한다. MBC/SBS/CBS/KBS 원천을 사용하며 충돌 시 다음 방송을 추측하지 않는다. 다른 원천 또는 조회 실패는 확인 불가와 공식 페이지 열기를 제공한다. 이미지 원천은 MBC/SBS이며 없는 경우 채널 커버를 표시한다.

일반 플레이어는 메뉴 막대/트레이 아이콘 위치에서 열리고 외부 클릭 시 숨긴다. 고정 버튼은 현재 실행 동안 창을 항상 위에 유지하며 외부 클릭으로 숨기지 않는다. 고정 중 제목 영역으로 드래그할 수 있고 해제하면 아이콘 위치로 돌아간다. 메뉴바 아이콘은 실제 재생 상태일 때 작은 재생 기호, 그 외에는 일시정지 기호를 표시한다.

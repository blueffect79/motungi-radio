# 외부 제공 인터페이스

공개 HTTP API·SDK·브라우저 원격 제어 인터페이스는 제공하지 않는다. 앱 내부 Tauri 명령은 버전 간 외부 연동 계약이 아니다.

OS 자동 실행 등록이 사용하는 실행 인자는 --autostart다. 입력에 이 인자가 있으면 트레이만 시작하고 창과 소리는 자동 시작하지 않는다. 출력은 로컬 앱 프로세스이며 텍스트 응답 프로토콜은 없다. 등록 실패는 앱 설정에 오류로 표시하며 성공 상태를 가정하지 않는다.

시험 설치파일은 macOS arm64/x64 DMG와 Windows x64 EXE이며 각 파일 옆 SHA256SUMS.txt에 SHA256과 파일명이 기록된다. 해시 불일치 파일을 정상 시험본으로 취급하지 않는다. 해시가 일치해도 게시자 인증이나 실제 호환성을 보장하지 않는다.

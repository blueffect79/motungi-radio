# 설치와 수동 업데이트

현재 0.2.1 비공개 시험본을 제공합니다. 전달받은 파일 또는 권한이 있는 GitHub Actions의 빌드 artifact에서 운영체제와 CPU에 맞는 설치파일 및 SHA256SUMS.txt를 함께 받습니다. 공개 Releases 배포는 아직 진행하지 않았습니다. 자동 업데이트는 지원하지 않습니다. 출처가 불명확한 파일은 설치하지 마세요.

| 환경 | 파일 이름 |
| --- | --- |
| macOS 13 이상 Apple Silicon | radiokorea-버전-macos-arm64.dmg |
| macOS 13 이상 Intel | radiokorea-버전-macos-x64.dmg |
| Windows 10/11 x64 | radiokorea-버전-windows-x64.exe |

## 파일 확인

macOS는 다운로드 폴더에서 `shasum -a 256 파일이름.dmg`, Windows PowerShell은 `Get-FileHash .\파일이름.exe -Algorithm SHA256`을 실행하고 SHA256SUMS.txt의 같은 파일명에 대응하는 값과 비교합니다. 해시는 파일 변경·손상 확인용이며 게시자의 신원 보증이 아닙니다.

## macOS

DMG를 열고 앱을 Applications로 복사한 뒤 실행합니다. 메뉴 막대 아이콘을 눌러 창을 엽니다. Dock에 계속 표시되는 일반 창 앱과 동작이 다릅니다.

현재 빌드는 ad-hoc 서명이며 Apple Developer ID 서명과 공증을 받지 않았습니다. 인터넷에서 받은 파일은 Gatekeeper에 의해 차단될 수 있습니다. 출처와 해시를 확인한 사용자가 실행을 선택하는 경우에만 시스템 설정 → 개인정보 보호 및 보안의 해당 앱 열기 허용 절차를 따르세요. 관리 기기 정책에 따라 허용되지 않을 수 있습니다. 보안 검사에서 악성 항목으로 보고하면 실행을 중단하세요. 전역 보안 해제는 필요하지 않습니다. 설치·최초 실행 흐름은 실기기 확인이 남아 있습니다.

## Windows

EXE를 실행해 현재 사용자 범위로 설치합니다. 관리자 권한이 없어도 설치하도록 설정했지만 기기 정책과 WebView2 설치에는 추가 제한이 있을 수 있습니다. WebView2 런타임이 없으면 설치기가 Microsoft에서 다운로드하므로 인터넷 연결이 필요합니다. 오프라인 완결 설치파일이 아닙니다.

현재 EXE는 코드 서명하지 않아 SmartScreen의 알 수 없는 게시자 경고가 나올 수 있습니다. 출처·해시 확인 후 본인이 신뢰하는 경우에만 기기에서 제공하는 개별 앱 실행 선택을 이용하세요. 조직 정책으로 차단될 수 있으며 Defender나 SmartScreen 전체를 끄지 마세요. Windows 10/11 x64는 목표 환경이며 실기기 설치·청취 확인은 아직 남아 있습니다.

실행 후 알림 영역의 아이콘을 누릅니다. 숨겨진 아이콘 목록에 들어갈 수 있습니다. 런타임 문제는 [Microsoft WebView2 배포 안내](https://developer.microsoft.com/microsoft-edge/webview2/)를 참고하세요.

## 업데이트·삭제

앱 메뉴에서 완전히 종료한 뒤 새 릴리스 파일을 받아 해시를 확인합니다. macOS는 Applications의 앱을 교체하고 Windows는 새 설치파일을 실행합니다. 설정 유지 여부는 릴리스별 업그레이드 검증 결과를 확인하세요. 앱 설정에서 로그인 시 자동 실행을 끈 후 macOS는 앱을 휴지통으로 옮기고 Windows는 설정의 설치된 앱에서 제거합니다. 삭제 후 사용자 설정 파일이 남을 수 있습니다.

방송이 안 나오면 네트워크와 공식 방송사 플레이어를 확인하세요. 서비스 중단·지역 제한·스트림 변경·편성 정보 미제공이 발생할 수 있습니다. 확인 불가 표시는 임의 프로그램명으로 대체하지 않습니다.

# 외부 데이터와 권한

사용자 계정·인증 토큰·역할별 권한 서버는 없다. PC 사용자는 앱의 로컬 설정과 자신의 OS 자동 실행 등록을 조작한다. 원격 웹페이지나 방송사 응답은 네이티브 명령을 실행할 권한이 없다.

방송사 응답의 재생 URL은 공식 서비스가 발급한 일시 데이터다. 메모리에서 재생에 사용한 후 버리며 소스·설정·로그·시험 결과에 전체 URL이나 토큰을 남기지 않는다. 만료하면 공식 서비스에서 다시 받는다. 인증·지역 제한을 회피하거나 토큰을 생성하지 않는다.

주소 조회는 HTTPS와 방송사별 허용 호스트·리다이렉트·크기·시간 제한을 검증한다. 검증 실패는 안전한 한국어 오류로 반환한다. 외부 제목은 텍스트로 표시하고 JSONP는 제한된 데이터로만 해석한다. 원격 스크립트 실행, 전역 CORS 해제, 임의 사용자 주소의 네이티브 요청은 허용하지 않는다.

운영 원격 분석과 청취 이력 수집은 없다. 배포 검증에는 코드 commit, 대상 CPU, 파일 해시, 명령 종료 코드, 통과·실패·미검증 범위만 기록한다. 개인 설정 내용이나 원천의 일시 URL을 진단 로그에 추가하지 않는다.

자체 MIT 코드는 방송 콘텐츠의 이용 허가를 포함하지 않는다. 기술 응답 성공과 공개 권한을 분리한다. 현재 인증서 비밀은 없으며, 향후 서명 비밀을 쓰면 저장소 대신 빌드 환경의 비밀 저장소에 두고 공개 로그에 출력하지 않는다.

프로그램 이미지는 HTTPS의 cbs.co.kr, img.imbc.com, image.cloud.sbs.co.kr, programres.kbs.co.kr, mediafactory.play.kbs.co.kr만 네이티브 정규화·프런트 검증·CSP에서 허용한다. 실패하면 채널 커버를 표시하고 재생은 유지한다. 공식 페이지 열기 명령은 채널 ID만 받아 정적 카탈로그 URL만 연다. 브라우저 검증 어댑터는 Vite serve의 ui-preview 모드에서만 연결되고 배포 빌드에는 포함하지 않는다.

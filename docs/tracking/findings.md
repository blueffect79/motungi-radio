# 남은 확인 사항

- TBN 공식 정보 페이지를 네이티브 TLS로 요청할 때 시간 초과가 발생한다. 13개 지역의 프로그램명이 확인 불가가 되지만 스트림 연결은 별도 확인됐다. 공식 응답과 클라이언트별 차이를 조사했으나 안정적인 네이티브 요청을 확보하지 못했다. 방송사 제공 방식이 바뀌거나 공식 지원 경로가 확보되면 정확한 지역 일치 검증과 함께 재시험한다.
- KBS 한민족 요청의 외부 채널 코드와 내부 응답 채널 코드가 다르다. 다른 방송 정보를 표시할 위험 때문에 확인 불가로 처리한다. 공식 매핑 근거가 없어 현재 임의 치환하지 않으며, 정확한 원천 확인 후 어댑터를 변경한다.
- MBC 현행 공개 클라이언트의 재링크 관련 고지에 대해 우리 앱의 공개 허가는 확인하지 못했다. 연결 성공이 공개 동의를 뜻하지 않아 일반 배포가 남아 있다. 권리자의 조건 확인이 필요하며 연락 발송은 별도 사용자 지시를 받아야 한다.
- Mac 화면은 잠겨 있었고 사용자는 나중에 직접 확인하기로 했다. Windows 11 Intel PC는 현재 원격 연결돼 있지 않다. 실제 청취·짧은 절전·로그인·보안 경고는 사용자 시험 결과가 오기 전까지 미검증이다.

- Tauri 명령의 실제 WebView 왕복은 아직 설치본에서 확인하지 못했다. 프런트 invoke 모의 테스트와 Rust envelope 테스트는 각각 통과했지만 실제 명령명·인자·성공 응답 연결을 모두 증명하지는 않는다. 화면 시험을 사용자가 나중에 하기로 했으므로 그때 채널 조회·설정 저장·재생 명령을 함께 확인한다.

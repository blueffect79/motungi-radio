## Linux 시험판 — 2026-10-10

Ubuntu 22.04 x64 `.deb`·`.AppImage` 빌드를 추가했다. GStreamer 미디어 라이브러리, 작업 표시줄 복원, 트레이 메뉴, logind 절전 복귀를 지원한다. 실제 배포판·소리 출력·로그인·절전 검증은 남아 있다. Linux CI 결과는 검증 기록에 별도로 추가한다.

`165b9c0` 설치본은 [Linux 시험판](https://github.com/devsejong/motungi-radio/releases/tag/v0.2.1-linux.1)으로 공개했다. Ubuntu 가상 화면에서 두 형식의 실행·미니 높이·설정·EBS 스트리밍 재생과 정지를 확인했다. 사람의 청취·실제 데스크톱 기능 시험은 별도다.

`9cdd45b`에서 제목을 오른쪽→왼쪽으로 이동하도록 수정하고 Mac 트레이의 파란색을 보존했다. 프런트 50개·네이티브 46개 통과, 두 플레이어의 제목 이동은 브라우저 화면에서 확인했다. 공개 0.2.1 및 Linux 시험판 설치파일에는 이 수정이 아직 포함되지 않는다. Apple 개발자 가입 승인·Developer ID 인증서 등록·키체인 공증 인증 설정을 마쳤다. 0.2.2 Mac 두 설치파일 서명·Apple 공증·공증 확인표·Gatekeeper 검증을 완료하고 공개했다. 제목·아이콘 수정은 이 Mac 릴리스에 포함된다.

## 로컬 UI 검토 — 2026-10-10

상단을 투명도 슬라이더·압정·설정 톱니바퀴 순서로 한 줄에 배치했다. 미니 버튼과 별도 축소 스타일을 제거하고 플레이어 아래에 채널 목록 접기·펼치기 버튼을 두었다. 기존 저장값은 채널 목록 표시 여부로 이어받는다. 목록을 접어도 프로그램 이미지와 재생 영역 크기는 유지한다.

프런트 53개·네이티브 48개 테스트와 웹 빌드 통과. 380px 로컬 프리뷰에서 상단 배치, 채널 토글, 설정 복귀와 밝은·어두운 화면을 확인했다. 사용자 디자인 검토를 마쳤으며 0.2.5로 배포했다.

채널 토글은 Apple Music·Spotify의 목록 버튼 방식을 참고해 목록 아이콘·동작 문구·펼침 화살표가 있는 36px 버튼으로 개선했다. 플레이어 카드 하단에 통합하고 구분선·강조 배경으로 클릭 영역을 표시한다. 열린 상태는 위쪽 화살표로 구분한다. 밝은·어두운 화면, Enter 전환과 포커스 유지, 접힌 창의 버튼 잘림 없음을 확인했고 기존 자동 검증도 통과했다.

## Mac 메뉴바 아이콘 — 2026-10-11 로컬 변경

흰색 라디오에 접힌 모서리·원형 스피커·기울어진 안테나를 더했다. 내부 상태 표시안은 철회하고, 재생·일시정지는 본체 밖의 별도 배지로 복원했다. 밝은 배경에서는 얇은 어두운 외곽선으로 구분한다. Windows·Linux 트레이는 기존 아이콘을 사용한다. 실제 아이콘 렌더러의 픽셀로 밝은·어두운 배경 프리뷰를 확인했다. 프런트 53개·네이티브 48개 테스트 통과. 설치된 앱의 메뉴바와 새 배포본은 아직 검증·갱신하지 않았다.

플레이어 제목 옆에 같은 형태의 테마 대응 라디오 로고를 추가했다. 카드 여백 16→12px, 이미지 104→88px, 재생 영역 위아래 간격을 줄였다. 380px 프리뷰에서 접힌 높이는 322→288px이며 라이트·다크 화면과 설정 복귀를 확인했다. 프런트 53개·네이티브 48개 테스트 통과. 로컬 수정이며 배포·설치본에는 아직 반영하지 않았다.

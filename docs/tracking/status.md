# 현재 상태

## 0.2.1 설치파일 — 2026-10-09

최신 UI 보완과 Retina 메뉴바 배치를 포함한 소스 `4b7a65f`로 Mac arm64·Intel DMG와 Windows x64 NSIS EXE를 생성했다. Mac 내부 앱 버전·실제 CPU·서명 무결성 및 DMG 검사, Windows Actions 37914476217의 테스트·실제 앱 CPU·EXE 형식 검사, 세 다운로드 파일의 SHA256 검증이 통과했다. 프런트 44개·네이티브 46개·패키지 5개 테스트 통과, 실시간 3개 제외. 파일과 빌드 근거는 `release-artifacts/0.2.1-4b7a65f/`, 상세 해시는 `docs/verification.md`에 기록했다.

현재 로컬 설치는 같은 기능 코드 `a9df600`의 0.2.0 앱이다. 이번 0.2.1 설치파일의 실제 설치·청취·업그레이드·로그인·절전은 미검증이다. Mac ad-hoc 서명·Windows 미서명 시험본이며 공개 릴리스는 발행하지 않았다. 아래 기록의 설치파일 미생성 표시는 각 변경 시점의 이전 상태다.

## 메뉴바 아래 기본 위치 — 2026-10-09

Retina에서 트레이 사각형의 물리 좌표가 논리 좌표 기반 모니터 조회에서 화면 밖으로 잘못 판정되는 경로를 수정했다. 모니터의 물리 경계로 대상을 찾고, 창을 아이콘 아래에 놓으며 화면 가장자리에서는 작업 영역 안으로 제한한다. 고정 중 드래그 위치는 유지한다. 프런트 44개·네이티브 46개 테스트 및 웹 빌드 통과. Mac 창 자동 조작이 응답하지 않아 실제 화면 위치는 사용자 확인이 남아 있다.

## 플레이어 제목·채널 컨트롤 — 2026-10-09

플레이어 제목 영역을 작은 채널명·시작/종료 시간, 프로그램명, 다음 프로그램 순으로 조정했다. 별도 정지 상태 문구를 제거하고 중앙의 재생/정지 아이콘으로 상태를 표시한다. 좌우 이전/다음 채널 버튼에 이동할 채널명을 표시하며, 전체 목록 순서의 첫/끝 채널을 순환한다. 기존 단일 플레이어의 선택·취소 경로를 사용한다.

프런트 44개·네이티브 45개 테스트 및 웹 빌드 통과. 실제 화면 코드와 공식 편성 데이터 스냅샷으로 전체 라이트·미니 라이트/다크 화면을 확인하고 `artifacts/ui-player-controls`에 캡처했다. 미니 높이는 이번 화면에서 252px이다. 이번 화면 변경은 기존 설치파일에 포함하지 않았다.

## UI 사용성 보완 — 2026-10-09

메뉴바/트레이 기준 창 열기(실행·중복 실행·크기 전환 포함), Retina 좌표의 이중 배율 보정 제거, 압정 고정·고정 중 제목 드래그, 실제 재생 상태 기반 아이콘 배지를 구현했다. 고정은 현재 실행 동안 유지하며 해제하면 아이콘 위치로 돌아간다. 다음 프로그램과 시작 시간을 플레이어에 표시하고, 날짜별 편성표에 지난·현재·다음 방송을 표시한다. 현재 방송 근처로 초기 스크롤한다. 불필요한 문구·숨김 버튼을 제거하고 미니 높이는 내용에 맞춰 조정한다. 새 설정의 기본 음량은 100이며 저장된 유효 음량은 유지한다.

프런트 43개·네이티브 45개 테스트 통과(실시간 3개 제외). 공식 메타데이터 스냅샷을 갱신하고 브라우저에서 전체/미니/설정/날짜 편성표를 검증·캡처했다(`artifacts/ui-refinements`). Mac .app 빌드는 통과했다. Mac 자동 UI 조작이 응답하지 않아 아이콘 위치·외부 클릭·드래그의 실기기 확인은 미검증이다. 이번 보완 이후 Windows 빌드 및 새 DMG/EXE는 만들지 않았으며, 아래 0.2.0 설치파일은 보완 이전 소스다.

## UI 개편 — 2026-10-09

`codex/player-redesign`에서 라이트/다크/시스템 모드, 설정으로 이동한 음량·음소거, 프로그램 이미지, 전체/즐겨찾기 탭, TBN 경인 한정(화면 20채널), 편성표, 같은 창의 미니 모드를 구현했다.

프런트 40개·네이티브 43개 자동 테스트 통과. 별도 live_schedules 실제 조회에서 MBC FM4U 16개, SBS 파워FM 5개, CBS 음악FM 4개, KBS 1FM 2개 시간 구간을 확인했다. 다음 편성을 제공하지 않는 원천은 공식 페이지 안내로 대체한다. 이미지는 MBC/SBS 두 원천을 사용한다.

Mac 개발용 .app 빌드 성공. Mac 잠금으로 네이티브 화면 검증은 미확인. 브라우저에서 같은 App.ts와 실제 정보 스냅샷으로 라이트·다크·설정·편성표·미니 화면을 검증하고 artifacts/ui에 캡처했다. 이는 네이티브 창 배치·오디오·OS 등록 검증을 대체하지 않는다. 0.2.0 설치파일은 소스 `162aa69`로 Mac arm64·x64 DMG 및 Windows x64 EXE를 생성했다. Mac 내부 앱 버전·아키텍처·서명 무결성과 DMG 체크섬, Windows Actions 37904725710의 테스트·실제 앱 아키텍처·EXE 형식 검사, 세 파일의 SHA256 검증을 통과했다. 파일은 `release-artifacts/0.2.0-162aa69/`에 보관한다. 서명·공증과 실기기 설치·청취·업그레이드는 미검증이며 공개 릴리스는 발행하지 않았다.

## 이전 시험본 기록

2026-10-09, 시험 앱 코드 91ffeb4 기준. 채널 32개, 단일 플레이어, TBN 지역 선택·즐겨찾기, 프로그램 표시, 로컬 설정, 트레이·무음 자동 실행, OS 복귀 알림이 구현됐다. 프런트 43개·네이티브 39개·패키지 5개 테스트 및 웹 빌드가 통과했다. 실시간 네이티브 테스트 2개는 일반 테스트에서 제외된다.

32개 스트림은 주소와 미디어 응답을 확인했다. 프로그램 정보는 18개 확인, TBN 13개와 KBS 한민족은 확인 불가다. Mac arm64/x64 DMG는 생성·무결성·아키텍처 검사를 통과했다. Windows x64 EXE도 GitHub 실행 37873884953에서 테스트·생성·앱 아키텍처·해시 검사를 통과했고 다운로드 사본의 SHA256도 일치한다.

남은 순서: 사용자의 Mac 및 Windows 11 Intel 실제 설치·화면·청취·로그인·절전 시험 → 문제 수정 → MBC 공개 조건 확인 → 공개 다운로드 검증. 사용자는 Mac 화면을 나중에 직접 확인하기로 했다. 최소 macOS 13, Intel 실기기, Windows 10 호환성은 미시험이다.

무료 GitHub 배포가 목표이며 현재 저장소는 비공개 시험 단계다. 향후 검토 대상은 서명·공증, 자동 업데이트, 앱스토어 등록이다. 모바일·Windows ARM·녹음·보이는 라디오·클라우드 동기화는 현재 구현 범위가 아니다.

코드와 프로젝트 지침은 독립 검토에서 차단 지적 없이 승인됐다. 이 판정은 실기기 시험이나 공개 배포 완료를 의미하지 않는다.

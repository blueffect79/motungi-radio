## 이번 변경

HLS 라이브러리를 필요할 때만 로드한다. 프로그램·채널 반복 검색을 Map 조회로 바꾸고 날짜 포매터를 재사용한다. 다음 방송은 정렬 없이 찾는다. 앱·홈페이지·설치 안내의 반복 설명을 줄였다.

프런트 50개·네이티브 46개 테스트 및 웹 빌드 통과. 초기 JS는 약 600KB → 27KB이며 HLS 574KB는 필요할 때 로드한다. 개발 전용 데이터로 380px 설정·편성표 화면을 확인했다.

## Linux 시험판 — 2026-10-10

Ubuntu 22.04 x64 `.deb`·`.AppImage` 빌드를 추가했다. GStreamer 미디어 라이브러리, 작업 표시줄 복원, 트레이 메뉴, logind 절전 복귀를 지원한다. 실제 배포판·소리 출력·로그인·절전 검증은 남아 있다. Linux CI 결과는 검증 기록에 별도로 추가한다.

`165b9c0` 설치본은 [Linux 시험판](https://github.com/devsejong/motungi-radio/releases/tag/v0.2.1-linux.1)으로 공개했다. Ubuntu 가상 화면에서 두 형식의 실행·미니 높이·설정·EBS 스트리밍 재생과 정지를 확인했다. 사람의 청취·실제 데스크톱 기능 시험은 별도다.

`9cdd45b`에서 제목을 오른쪽→왼쪽으로 이동하도록 수정하고 Mac 트레이의 파란색을 보존했다. 프런트 50개·네이티브 46개 통과, 두 플레이어의 제목 이동은 브라우저 화면에서 확인했다. 공개 0.2.1 및 Linux 시험판 설치파일에는 이 수정이 아직 포함되지 않는다. Apple 개발자 가입 승인 후 인증서 발급·공증 인증 준비 중이다.

# 소개 페이지 UI 리서치

기준일: 2026-10-09. 실제 공식 사이트의 첫 화면·정보 구조를 확인했다. 아래 적합도는 서비스 성능이나 전환율 측정이 아니라 모퉁이 라디오의 제품 성격에 대한 디자인 판단이다.

## 비교

MusicBee와 Apple Music도 초기 검색 후보였으나, 음악 라이브러리·구독 서비스보다 소형 데스크톱 유틸리티의 소개 방식이 더 가까워 위 세 사례를 주 비교 대상으로 삼았다.

## 추천 디자인

**Sleeve의 제품 쇼케이스 구조 + Doppler의 플랫폼별 설치 안내.** 다른 서비스의 에셋이나 문구를 복사하지 않고 자체 HTML/CSS/SVG로 구현한다.

- 첫 화면: 제품명과 짧은 한국어 가치 제안, 설치 안내로 가는 주요 버튼, 크게 보이는 데스크톱 플레이어 장면
- 화면 경험: 전체/미니 미리보기와 라이트/다크 전환. 실제 방송 재생처럼 보이지 않도록 예시 표시
- 기능 소개: 반복된 작은 설명 카드 대신 사용 장면별로 큰 화면과 짧은 문장을 묶음
- 색상: 흰색/검정색을 바탕으로 기존 플레이어의 파란색을 버튼·선택 상태에 제한. 방송 콘텐츠를 덮는 색 면은 줄임
- 설치: Mac Apple Silicon·Intel / Windows x64 구분. 시험 상태와 미서명·미공증을 설치 영역에 표시
- 모바일: 설명 → 플레이어 → 기능 → 설치의 순서 유지. 두 화면을 억지로 나란히 축소하지 않음

## 검증 기준

1. 첫 화면만 보고 한국 채널용 PC 라디오 앱과 Mac/Windows 지원을 이해할 수 있다.
2. 전체/미니, 라이트/다크 컨트롤에 선택 상태·접근성 이름을 제공한다.
3. 작은 모바일부터 데스크톱까지 콘텐츠 가로 넘침이 없다.
4. 설치 안내에 현재 버전·OS·공개 다운로드 준비 상태를 찾을 수 있다.
5. 공식 방송 주소·로고·프로그램 이미지, 분석이나 외부 미디어를 사이트에 추가하지 않는다.

다운로드 전환율이나 방문자 호응은 측정하지 않았다. 시각 참고 사이트와 제품 적합도 판단을 구분한다.

## 구현 결과

추천한 제품 쇼케이스 구성을 기준으로 페이지를 개편했다. 가운데 제목과 설치 안내, 넓은 데스크톱 장면의 전체/미니 플레이어, 사용 장면별 교차 배치 설명을 적용했다. 전체/미니 선택 버튼과 앱 안의 미니 버튼은 동일 상태를 변경하며 `aria-pressed`를 함께 갱신한다. 흰색·검정색 테마를 유지하고 주 색상은 기존 앱의 파란색을 사용한다.

페이지에는 원본 사이트의 이미지·프로그램 아트·고객 평가를 복제하지 않았다. 기능 화면은 자체 HTML/CSS/SVG 예시이며 실제 라디오 재생을 제공하지 않는다. 방문자 반응이나 다운로드 전환율은 미측정이다.

# 화면과 프런트 조합

화면 렌더링·접근성·네이티브 어댑터 조합을 소유한다. 방송사 URL 파싱과 OS 등록은 이 영역에서 직접 구현하지 않는다.

원격 제목은 textContent로만 넣는다. 볼륨 입력과 재생 버튼은 상태 갱신 때 불필요하게 교체하지 않아 드래그·키보드 포커스를 보존한다. 즐겨찾기와 전체 목록에 같은 채널이 있어도 포커스 키는 목록별로 다르게 둔다.

검증: npm run verify. 긴 제목, 목록 중복, 정보 실패, 저장 지연 동안의 후행 입력을 jsdom에서 재현한다. 실제 창 위치·청취 결과는 별도 기록한다.

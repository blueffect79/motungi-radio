# 채널 선택

채널 행의 순서·이동 포함 여부와 직접 선택을 소유한다. 미디어 요청·파일 저장·방송사 응답 해석은 다른 계층에서 수행한다.

2026-10-26 승인 변경: 즐겨찾기를 제거하고 드래그·방향키 순서 변경과 비활성화로 대체한다. 비활성 채널은 이전·다음 이동에서 제외하되 직접 선택과 현재 청취는 유지한다. 순서는 모든 플레이어 모드에서 동일하다. 신규 채널은 마지막에 추가한다.
TBN은 경인만 노출한다. 삭제된 마지막 채널을 다른 채널로 임의 치환하지 않는다.

검증: 순서 저장, 취소된 드래그, 비활성 직접 선택, 순환 이동과 전체 비활성화, 저장 실패·지연·무음 복원을 확인한다.

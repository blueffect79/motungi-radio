# 단일 재생기

오디오 수명·재생 의도·주소 요청 취소를 소유한다. 프로그램 정보와 설정 저장 성공 여부가 오디오 상태를 지배하지 않게 한다.

취소에는 프런트 AbortSignal과 네이티브 requestId가 함께 쓰인다. 오래된 응답·콜백은 최신 세대를 바꾸지 못한다. playing은 미디어 이벤트로만 확정한다. OS 복귀는 네이티브 이벤트로 받으며 focus를 복귀로 취급하지 않는다.

검증: controller/transport/invoke/lifecycle 테스트를 실행한다. 연결 중 정지, 늦은 응답, 20초 로딩·재버퍼링 제한, 늦게 완료된 이벤트 구독 해제, 복귀 실패 후 수동 재시도를 포함한다.
